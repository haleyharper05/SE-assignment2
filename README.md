# SE-assignment2

## Project Description
This project simulates memory allocation strategies such as first-fit, next-fit, and best-fit.

## Installation Instructions
1. Clone the repository:
   git clone https://github.com/haleyharper05/SE-assignment2.git

2. Navigate to the folder:
   cd SE-assignment2

3. Compile the program (for C++):
   g++ hello.cpp -o hello

## Usage
Run the program:
./hello
